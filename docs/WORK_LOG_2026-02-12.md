## 4. Vercel 빌드 오류 수정

### `frontend/lib/utils.ts` 생성 (`60e160a`)
빌드 시 `@/lib/utils` 모듈을 찾을 수 없는 오류 해결. 다음 유틸리티 함수 포함:

| 함수 | 설명 |
|------|------|
| `cn(...inputs)` | Tailwind 클래스 병합 (clsx + tailwind-merge) |
| `getImageUrl(path, size)` | TMDB 이미지 URL 생성 |
| `formatDate(date)` | "YYYY년 MM월 DD일" 한국어 날짜 포맷 |
| `formatRuntime(minutes)` | "Xh Ym" 런타임 포맷 |
| `getMBTIColor(mbti)` | 16개 MBTI 타입별 Tailwind 색상 반환 |

### `getMBTIColor` 함수 추가 (`4a734f3`)
- 16개 MBTI 타입에 대한 색상 매핑
- E 유형: purple, pink, red, orange 등
- I 유형: indigo, violet, blue, emerald 등
- 기본 fallback: gray

### TMDB 이미지 사이즈 전체 지원 (`016fc8f`, `3dcb249`)
- 최종 지원 사이즈: `"w92"|"w154"|"w185"|"w200"|"w300"|"w342"|"w500"|"w780"|"original"`
- `app/movies/[id]/page.tsx` → `w342` 사용
- `app/ratings/page.tsx` → `w185` 사용
- `components/search/SearchAutocomplete.tsx` → `w92` 사용

### `.gitignore` 이슈
- 루트 `.gitignore`의 `lib/` 규칙이 `frontend/lib/` 까지 무시
- `git add -f frontend/lib/utils.ts` 로 강제 추가하여 해결
