## 1. useMbti / useMood 훅 신규 생성

**파일**: `frontend/hooks/useMbti.ts`, `frontend/hooks/useMood.ts`

### 설계 원칙

`useWeather`와 동일한 패턴으로 구현 — CustomEvent 기반 전역 동기화.

### useMbti

- `selectedMbti` 전역 상태 관리
- 초기값: 비로그인 → `"ENFP"`, 로그인+MBTI 설정 → `user.mbti`, 로그인+미설정 → `null`
- `setManualMbti()` 호출 시 `recflix-mbti-change` 이벤트 발행
- 모든 `useMbti` 인스턴스가 이벤트 수신하여 동기화
- 로그인/로그아웃 시 `isManual` 플래그가 없으면 자동 동기화

### useMood

- `selectedMood` 전역 상태 관리
- 기본값: `"tense"`
- `setManualMood()` 호출 시 `recflix-mood-change` 이벤트 발행
- 모든 `useMood` 인스턴스가 이벤트 수신하여 동기화

## 4. race condition 방지

**문제**: `app/page.tsx`에 `cancelled` 플래그가 없어, MBTI를 빠르게 연속 변경 시 느린 이전 응답이 최신 응답을 덮어쓸 수 있었음.

**수정 내용**:

```typescript
useEffect(() => {
  let cancelled = false;
  const fetchRecommendations = async () => {
    const data = await getHomeRecommendations(...);
    if (!cancelled) {
      setRecommendations(data);
      setError(null);
    }
    // ...
  };
  fetchRecommendations();
  return () => { cancelled = true; };
}, [...]);
```

## 5. MBTI 파라미터 우선순위 수정

**문제**: 비로그인 시 `!isAuthenticated ? "ENFP"` 조건이 `selectedMbti`보다 먼저 평가되어, 헤더에서 MBTI를 바꿔도 항상 `mbti=ENFP`로 API 호출됨.

**수정 전**:
```typescript
!isAuthenticated ? "ENFP" : (selectedMbti ?? undefined)
```

**수정 후**:
```typescript
selectedMbti ?? user?.mbti ?? "ENFP"
```

**우선순위**: `selectedMbti` > `user.mbti` > `"ENFP"`
