## 6. 정반대 MBTI 추천 섹션 추가

`backend/app/services/recommendation.py`에 `OPPOSITE_MBTI` 매핑 테이블 및 `opposite_mbti_row` 추가

```python
OPPOSITE_MBTI = {
    "INTJ": "ESFP", "ESFP": "INTJ",
    "INTP": "ESFJ", "ESFJ": "INTP",
    "ENTJ": "ISFP", "ISFP": "ENTJ",
    "ENTP": "ISFJ", "ISFJ": "ENTP",
    "INFJ": "ESTP", "ESTP": "INFJ",
    "INFP": "ESTJ", "ESTJ": "INFP",
    "ENFJ": "ISTP", "ISTP": "ENFJ",
    "ENFP": "ISTJ", "ISTJ": "ENFP",
}
```

- 타이틀: `🔀 정반대 MBTI 추천`
- 로그인 시 설명: `나와 완전히 다른 {opposite_mbti} 유형의 영화, 색다른 경험이 될 거예요`
- 비로그인 시 설명: `나와 다른 시각으로 세상을 보는 영화들이에요`
- 비로그인 기본값: `ENFP`
- rows 순서: `mbti → opposite_mbti → weather → mood → popular → top_rated` (로그인)
